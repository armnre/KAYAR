# هویت بصری کاپوش در کایار

**کایار** نام اپلیکیشن است؛ برند لباس‌ها **کاپوش** است. روی لباس‌ها هرگز «KAYAR» نمی‌آید — فقط نشان K داخل کادر و لوگوی دست‌نویس kapoosh.

## لوگو
- فایل رسمی: `apps/kayar/public/brand/logo.svg` (۱۳۷×۴۶، سفید + لیمویی). نشان مربعی: `brand/logo-mark.svg` (برش مستقیم از همان فایل، بدون بازطراحی).
- فقط روی پس‌زمینه‌ی تیره. نسخه‌ی روی روشن/مونوکروم هنوز از برند گرفته نشده.
- حداقل ارتفاع: لوگوی کامل ۲۴px، نشان ۱۶px. فضای خالی اطراف: حداقل نصف ارتفاع نشان K.
- آیکن‌های PWA، favicon و OG فقط از همین SVG ساخته شده‌اند.

## رنگ
| نقش | مقدار |
|---|---|
| تأکید برند (primary) | `#E4FF1A` — `67 100% 55%` |
| پس‌زمینه | `#0A0C0E` |
| متن روی لیمویی | `#0B0D0E` |
لیمویی روی پس‌زمینه‌ی تیره کنتراست بالای ۱۴:۱ دارد؛ هرگز به‌عنوان رنگ متن روی پس‌زمینه‌ی روشن استفاده نشود.

## تصاویر
- همه‌ی تصاویر داخل `public/` سرو می‌شوند؛ هیچ تصویر/فونت/اسکریپت خارجی.
- عکس‌های محصول فعلی thumbnail (حدود ۲۲۵×۳۰۰) هستند: فقط در اندازه‌ی کارت، هرگز بزرگ‌نمایی.
- webp + fallback jpg، width/height مشخص، lazy به‌جز هیرو.
- تصویر تولیدی هوش مصنوعی هرگز متن/لوگو نسازد؛ لوگو بعداً به‌صورت SVG روی تصویر قرار می‌گیرد.
