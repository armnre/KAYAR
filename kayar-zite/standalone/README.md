# KAYAR — نسخه‌ی مستقل (بک‌اند + سایت روی سرور خودتان)

این نسخه کل کایار (سایت، همه‌ی ۴۵ API، دیتابیس، آپلود فایل) را روی سرور خودتان اجرا می‌کند و هیچ وابستگی‌ای به Zite یا سرویس خارجی ندارد.

## استقرار روی لیارا
1. در لیارا یک **دیتابیس PostgreSQL** بسازید و «آدرس اتصال خصوصی» آن را کپی کنید.
2. در لیارا یک **دیسک** با نام `uploads` برای اپ بسازید (برای فایل‌های آپلودی ادمین).
3. اپ Docker لیارا (پورت `3000`) — متغیرهای محیطی:
   - `DATABASE_URL` = آدرس اتصال PostgreSQL
   - `PUBLIC_URL` = آدرس سایت، مثلاً `https://kayarapp.liara.run`
   - `ZITE_BOOTSTRAP_ADMIN_USERNAME` و `ZITE_BOOTSTRAP_ADMIN_PASSWORD` = نام کاربری/رمز اولین مدیر (حداقل ۱۰ کاراکتر)
   - `ZITE_NARAROUTER_API_KEY` = کلید دستیار هوشمند
   - (اختیاری) کلیدهای پیامک/درگاه پرداخت اگر استفاده می‌کنید
4. Zip پوشه‌ی `kayar-zite` را آپلود و Deploy کنید.

در اولین اجرا جدول‌ها خودکار ساخته می‌شوند و محتوای پایه (حرکات ورزشی، غذاها، آهنگ‌ها) از `seed/data.json.gz` وارد می‌شود. اطلاعات خصوصی (اعضا، رمزها، نشست‌ها) در گیت‌هاب نیست؛ اعضا را از پنل ادمین دوباره بسازید.

## اجرای محلی
```
npm install && cd standalone && npm install && node build.mjs
DATABASE_URL=postgres://... PUBLIC_URL=http://localhost:3000 node dist/server.mjs
```
